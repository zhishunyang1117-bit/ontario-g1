# 安省 G1 笔试题库（2026-10 整理）

根据安大略省官方《Official MTO Driver's Handbook》在线版（2026-10-12 抓取）原创编写的中英对照练习题库，共 **723 题**：交通规则 518 题，标志、信号灯与路面标线 205 题。每题都有答案、中文解析和手册出处链接。

> 这些是练习题，不是官方真题。DriveTest 不公开题库，真题的措辞会不一样，但考点都出自同一本手册。

## 怎么用

1. 先看 `01_考试须知.md`，再把 `02_必背要点.md` 过一遍（这两份内容在网页的「必背速查」里也能直接看、能搜索）。
2. 双击 `05_模拟练习.html` 用浏览器打开练习。界面和题库可离线使用，标志图片需要联网；练习模式图片加载失败时可以参考文字描述，模拟考试只提示图片无法加载并提供重试，避免提前透露答案。
3. 想按章节看题和解析，就读 `03`、`04` 两个 md 文件（VS Code、Typora 预览效果最好）。
4. 考试时如果选英文卷，建议练习时切到 “EN” 模式，熟悉英文题干。

## G1 Studio 功能一览

- **学习总览**：一键开始 20 题今日练习；首页显示今日复习、今日进度、连续学习天数、已练题目、正确率、错题本和收藏；最近 7 天练习量图（带每日目标线）；列出正确率最低的章节，点一下就练。
- **今日复习（间隔重复）**：答过的题自动排进复习计划——答错的第二天再出现，答对后复习间隔依次拉长到 2、4、7、15、30 天；首页显示今天到期的题和未来 7 天的复习量，可以先复习 20 题或一次复习全部。复习时答对的错题会移出错题本。更新前的学习记录第一次打开时自动排期：错题当天到期，其余练过的题分散到之后一周。
- **考前冲刺**：已经掌握的题不再出；先出错题本里的题，再出练过但没掌握的题，最后才是没练过的题（挑战难度优先）。可选范围（交规/标志）、题量，也可以只练练过的题。
- **分类练习**：11 个主题，可搜索章节、按交通规则/道路标志筛选，选基础/进阶/挑战难度、10/20/40/全部题量、随机顺序、只练未掌握的题。
- **答题体验**：中英、中文、英文三种显示；答完立即看对错、解析和官方手册出处；收藏、个人笔记、标记回看、答题卡跳题。
- **模拟考试**：随机 20 道标志 + 20 道交规，交卷前可改答案、不显示对错和标志描述；成绩页用圆环显示正确率，两部分各画出 80% 及格线，任何一部分不到 16 题都判为未通过。
- **模拟考历史**：考试页和统计页显示历次成绩的折线图（带 80% 及格线，实心点为通过、空心点为未通过）、已考和通过次数、最高正确率、最近 5 次平均，以及全部成绩表；更新后交卷的考试会同时记下标志和交规两部分的得分。
- **保存与续练**：刷新、关闭或保存退出后，可在首页继续上次练习；重新开一组前会先确认。页面切到后台或手机锁屏时计时暂停。
- **错题与收藏**：支持关键词和章节筛选；错题复习答对后自动移出。可把当前列表导出成 Markdown 或 CSV（Excel 直接打开），或打印成带答案解析的复习单、不带答案的练习卷（答案附在最后）。
- **必背速查**：`02_必背要点.md` 和 `01_考试须知.md` 的全部内容，按章节目录浏览；搜索时只留下命中的段落、表格行和列表条目，关键词高亮；可以打印。
- **题库搜索**：在 723 道题的题干、选项、解析和标志描述里搜索，中英文都行，不分大小写和全角半角，多个关键词用空格隔开；结果里可以直接看答案解析、练这道题或收藏。
- **学习统计**：累计作答、正确率、连续学习天数、模拟通过次数；最近 12 周的学习日历；题库覆盖（已掌握 / 练过未掌握 / 未练）；每章掌握情况，点一下练该章最需要巩固的 20 题；最近完成的练习。
- **外观**：深浅色（新用户默认跟随系统）、大字号、答题专注模式（导航收起，答题卡改为按钮打开的抽屉）。
- **手机**：底部标签栏（总览、练习、考试、速查、更多）；答题时底部固定「上一题 · 答题卡 · 下一题」，答题卡从底部弹出；分类练习页底部常驻「开始练习」。
- **数据**：学习记录 JSON 导出/导入（备份里也包含复习计划），能导入旧版网页导出的备份；同时开两个窗口也不会互相覆盖记录。
- **快捷键**：`1–4` 或 `A–D` 选答案，`Enter` 下一题，`Shift+B` 收藏，`Esc` 关闭菜单或答题卡；输入笔记或搜索时不会触发答题。

练习记录保存在当前浏览器。继续使用原路径、原浏览器可读取旧版记录；换浏览器、复制到其他路径或改用本地预览地址时，请先在“偏好与数据”导出记录，再到新位置导入。

只更新网页而不重新生成题库文档：

```powershell
python D:\ontario-g1\tools\build.py --html-only
```

不带 `--html-only` 时，仍按原流程生成全部文档、CSV 和网页。修改界面源文件后需要重新运行生成命令。

## 开发与测试

- `python tools/build.py --check`：检查 `05_模拟练习.html` 是否已按源文件重新生成（不写文件）。
- `node tests/run.js`：一条命令跑完全部自动化测试。需要 Node 18 以上和 Playwright（Chromium）；测试会拦截所有外网请求，用无头浏览器把首页、分类练习、模拟考试、错题、收藏、笔记、统计、偏好设置、导出导入（含旧版备份）、刷新续练、快捷键和图片兜底都跑一遍。
- `node tests/screenshots.js`：在桌面、手机和深色模式下给主要页面截图，保存在 `screenshots/`（不提交）。

## 题目是怎么做出来的

1. 把手册 27 个相关章节抓成纯文本（`handbook_text/`）。
2. 按章节分 11 组，各组出题时都要求覆盖每个可考的数字和规则，每张标志、信号灯、标线图至少出一题。
3. 每组交给另一个代理逐题对照手册原文核对：答案有没有依据、数字是否准确、有没有第二个也说得通的选项、标志图片和答案是否对应。
4. 再做一轮中文译文和题目质量润色。
5. 查漏：两个审查代理把全部题干和手册逐章对照，找出没覆盖的考点；据此补出 92 道题，补的题同样经过独立核对。
6. 人工检查：
   - 用脚本把每道标志题的图片和手册里该图前面的说明逐条对照
   - 正确答案里的数字逐一到出处原文里查找
   - 删掉 46 道重复题
   - 复核审查代理标出的可疑题

## 需要注意

- **酒驾路边处罚需以现行规定为准**。ontario.ca 上的现行规定是：警告区间和零容忍首次停牌 7 天加 $250 罚款，第二次 14 天，第三次 30 天。手册第 22 节（2022 年版）还写着 24 小时，以及警告区间首次 3 天、第二次 7 天。
  - 题库按现行规定出题，相关的 5 题（LB-39、LB-42、LB-43、LB-93、LB-94）已按现行规定核对，并删除了建议根据旧选项选择过时处罚的说法。较长路边停牌期限自 2026-01-01 生效；2026-07-01 的部分刑事处罚变动应另行区分。
- **考试形式**：官方只说笔试分 2～3 个部分、总分至少 80% 才能通过，没有公布题数。“40 题、两部分各答对 16 题”只是常见说法。练习网页按每部分都要达到 80% 来判定，标准偏严。
- 来源：[Official MTO Driver's Handbook](https://www.ontario.ca/document/official-mto-drivers-handbook)、[DriveTest](https://drivetest.ca/)。规则以官方最新版本为准。
